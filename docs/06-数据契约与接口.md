# 06 · 数据契约与接口

改动的边界：`find_fast_core.py` **只新增函数**；`find_fast_web.py` 扩展 `/api/search`、`/api/rows`；`find_fast_gtk.py` 内部数据流自洽。所有新增字段对旧调用方是**可选**的——缺字段时前端要退化为纯文本（不报错）。

## 6.1 core 新增函数

全部放进 `find_fast_core.py`，纯函数、无 I/O、无全局状态，便于单测。

### `category(name, is_folder) -> str`

```python
CATEGORY_EXTS = {
    'doc':     ('pdf','doc','docx','xls','xlsx','ppt','pptx','txt','md','csv','rtf','odt','wps','et','dps'),
    'image':   ('png','jpg','jpeg','gif','webp','svg','bmp','heic','ico'),
    'archive': ('zip','tar','gz','7z','rar','xz','bz2','iso'),
    'code':    ('py','js','ts','jsx','tsx','html','css','json','yml','yaml','sh','java','c','cpp','go','rs','toml','sql'),
    'audio':   ('mp3','wav','flac','ogg','m4a','aac'),
    'video':   ('mp4','mkv','mov','avi','webm','flv'),
}

def category(name, is_folder=False):
    """'folder' | 'doc' | 'image' | 'archive' | 'code' | 'audio' | 'video' | 'other'"""
```

- `is_folder` 为真直接返回 `'folder'`（不看扩展名）。
- 扩展名取最后一个 `.` 之后，小写；无点 → `'other'`。
- 分类表用 `frozenset` 预处理成 `EXT2CAT`，查表 O(1)，**不要**每次遍历元组。
- 大小写不敏感：`.PDF` → `doc`。

### `category_group(cat) -> str`

`'video' → 'audio'`，其余原样。所有 UI 计数与筛选都用**分组后**的键（7 个：folder/doc/image/archive/code/audio/other）。`category()` 的 `video` 只用于详情里的「MP4 文件」这种类型文字。

### `short_dir(dir, keep=2) -> str`

```python
def short_dir(dir, keep=2):
    s = dir
    home = HOME  # 已有的模块级常量
    if home and home != '/' and (s == home or s.startswith(home + '/')):
        s = '~' + s[len(home):]
    parts = s.split('/')
    if len(parts) <= keep + 1:
        return s
    return '…/' + '/'.join(parts[-keep:])
```

| 输入 | 输出 |
|---|---|
| `/home/u/文档/项目甲` | `~/文档/项目甲` | <!-- sensitive-scan: ignore -->
| `/root/proxy/data/logs` | `…/data/logs` | <!-- sensitive-scan: ignore -->
| `~/下载` | `~/下载` |
| `/media/u/U盘备份` | `/media/u/U盘备份`（段数 4 > 3 → `…/u/U盘备份`，按实际段数算） | <!-- sensitive-scan: ignore -->
| `/` | `/` |

注意：`/media/u/U盘备份` → parts `['','media','u','U盘备份']` 长度 4 > 3 → `…/u/U盘备份`。这是期望行为（末两级）。 <!-- sensitive-scan: ignore -->

### `human_time_short(ts, now=None, lang=None) -> str`

| 条件 | zh | en |
|---|---|---|
| `now - ts < 60s` | `刚刚` | `just now` |
| `< 1h` | `N 分钟前` | `N min ago` |
| `< 24h` | `N 小时前` | `N h ago` |
| `< 7d`（整 7 天起不再说「天前」） | `N 天前` / `1 天前` | `N days ago` / `1 day ago` |
| 同年 | `MM-DD` | `MM-DD` |
| 其他年份 | `YYYY-MM-DD` | `YYYY-MM-DD` |
| `ts > now` 且差值 >60s（时钟偏移） | `YYYY-MM-DD` | 同 |

- 旧的 `human_time()`（`YYYY-MM-DD HH:MM`）**保留**，详情面板与 tooltip 继续用它。
- `lang` 缺省走 `ui_language()`；相对词进 `STRINGS`（`time_now` / `time_min` / `time_hour` / `time_day` / `time_days`），日期部分与语言无关。
- 边界：59s → `刚刚`，60s → `1 分钟前`，6 天 23 小时 → `6 天前`，整 7 天 → 绝对日期。

### `highlight(text, clauses, mode='html', mark_bg=None, mark_fg=None) -> str`

```python
def highlight(text, clauses, mode='html', mark_bg=None, mark_fg=None):
    """`text` 按 `clauses`（core.parse_query 的返回值）中的正向词做标记，返回转义后的字符串。
    mode: 'html' 用 <mark>；'pango' 用 <span background=... foreground=...>。
    未命中时返回转义后的原文。
    """
```

规则（逐条实现，测试见 `tests/test_highlight.py`）：

| # | 规则 |
|---|---|
| 1 | 只处理 `clause.negate == False` 的 clause；其 `alts` 里每个 term 都参与 |
| 2 | `NameTerm` / `WordTerm` / `PathTerm`（无 rx）：大小写不敏感的子串，标**全部**出现位置 |
| 3 | `AffixTerm`（`*.pdf`、`report*`）：head 标前缀、tail 标后缀；两者都命中时标整串 |
| 4 | `PatternTerm`：`rx.finditer` 每个匹配；零宽匹配跳过 |
| 5 | `ExtTerm`：文本以 `.ext`（大小写不敏感）结尾时标该后缀；`suffixes` 里多个取命中的那个 |
| 6 | 其他 term 类型（大小 / 日期等）忽略 |
| 7 | 区间先合并重叠与相接，按起点排序，最多 24 段；超出截断（保留靠前的） |
| 8 | 转义在产品逻辑内完成，**先转义再插入标记**，不允许把未转义文本拼进 HTML |
| 9 | `mode='pango'` 输出 `<span background="#ffe9a8" foreground="#14181d">`；`foreground` 仅在 `mark_fg` 非空时写 |
| 10 | 空 `clauses` 或空 `text` → 返回转义原文 |
| 11 | 不改原字符串、不缓存全局状态；调用方可用 `functools.lru_cache` 包一层 |

复杂度：O(len(text) × terms)，text 是文件名或短路径，实测 <0.1ms/行。**只对要渲染的行调用**。

### `highlight_row(name, dir_display, clauses) -> (name_html, dir_html)`

便捷封装：名称优先，名称里已标到的词不再在路径里标（避免同一词两处高亮）。返回两个 HTML 串。GTK 侧同参数调 `mode='pango'`，颜色按主题传入。

## 6.2 HTTP 契约

### `GET /api/search`

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `q` | str | `''` | 查询 |
| `page` | str | 随机 | 标签页标识（防多标签串结果） |
| `sort` | str | `mtime` | `mtime/name/size/path` |
| `desc` | `0/1` | `1` | 降序 |
| `regex` | `0/1` | `0` | 整串正则模式 |
| `limit` | int | 100 | 返回行数，上限 500（保持现状） |
| `type` | str | `all` | **新增**：`all/folder/doc/image/archive/code/audio/other` |
| `scope` | str | `''` | **新增**：目录前缀，空为不限 |
| `sid` | str | `''` | **新增**：上一结果的 sid；相同查询下复用结果，只重建视图 |

响应：

```json
{
  "sid": "3f9a1c2b",
  "count": 701,
  "ms": 1.6,
  "facets": {"all": 701, "folder": 1, "doc": 5, "image": 695,

  "scope_suggest": [{"dir": "/root/图片", "count": 696}, {"dir": "/root/文档", "count": 4}],

    {

      "name": "截图 2026-09-07 03.05.37.png",
      "name_html": "截图 <mark>2026</mark>-09-07 03.05.37.png",

      "dir_html": "…/<mark>图片</mark>/截图",
      "path": "/root/图片/截图/截图 2026-09-07 03.05.37.png",

      "ver": null,
      "ver_count": null,
      "ver_newest_path": null
    }
  ],
  "versions": "ready"

```

约定：

- `count` 是**当前 type/scope 过滤后**的总数，不是全量。全量在 `facets.all`。
- `facets` 永远包含 8 个键（含 0），前端不用判断缺失。
- `scope_suggest` 仅在 `facets.all > 400` 且 `scope == ''` 时给，最多 2 项，按计数降序；目录按「前两级」聚合（`/a/b/c` 与 `/a/b/d` 都归 `/a/b`）。
- `time` 用 `human_time_short`；`human_time` 仍在 `path` 的 tooltip 里用。
- `name_html` / `dir_html` 缺失时前端退回 `textContent`（旧服务兼容）。
- 排序在 core 完成，过滤**不重排**：视图保持原顺序。

### `GET /api/rows?page&sid&offset&limit`

不变，但 `offset` 现在作用在**视图**上（过滤后的序号），返回的 `k` 仍是原始结果序号。sid 失效返回 409（现状）。

### 错误

保持现状：`{"error": "正则表达式有误：…", "count": 0, "rows": []}`，HTTP 200。新增：`type` 非法值时忽略（按 `all` 处理），不报错。

## 6.3 视图映射与 facets 实现

`find_fast_web.py` 的 `Service.results[page]` 现在是 `(sid, res, holder)`，`holder` 只存 `{'groups': …}`。扩展为：

```python
holder = {'groups': None, 'facets': None, 'view': None, 'type': 'all', 'scope': ''}
```

### 计算 facets（每份结果一次，O(n)）

```python
def facets_of(res, n):
    counts = dict.fromkeys(('folder','doc','image','archive','code','audio','other'), 0)
    for k in range(n):
        name, folder, size, _mtime = res.row(k)
        counts[category_group(category(name, size < 0))] += 1
    counts['all'] = n
    return counts
```

- 只算一次，存 `holder['facets']`。
- 1M 条目约 0.3–0.6s：**必须放在搜索返回后异步算**，或以 `facets: null` 先返回再补（见 `docs/07` 的性能预算）。推荐：`n <= 200_000` 时同步算，超过则先返回 `facets: null`，前端下一帧带 `sid` 再请求一次。

### 构建视图（每次切 type/scope，O(n)）

```python
def build_view(res, n, type_, scope):
    if type_ == 'all' and not scope:
        return None                      # None 表示恒等视图，rows() 直接用 k
    out = []
    prefix = scope.rstrip('/') + '/' if scope else ''
    for k in range(n):
        name, folder, size, _ = res.row(k)
        if type_ != 'all' and category_group(category(name, size < 0)) != type_:
            continue
        if scope and not (folder == scope or folder.startswith(prefix) or
                          (size < 0 and os.path.join(folder, name) == scope)):
            continue
        out.append(k)
    return out
```

`rows()` 映射：

```python
view = holder.get('view')
k = view[i] if view is not None else i     # i 为 offset 后的序号
```

`count` = `len(view)`（None 时 `n`）。

### `sid` 复用

`/api/search` 收到与 `self.results[page]` 相同 sid 且 `q/sort/desc/regex` 未变时：
不重跑 `index.search`，只 `build_view` + 复用 `facets`，返回同一 sid。这样切换类型不会让「最新 / 有更新版」标签闪一下。

## 6.4 GTK 数据流

`ListStore(str, str, str, str, str, str, str)` → 追加两列：

| 下标 | 内容 | 用途 |
|---|---|---|
| 0 | 主题图标名 | 现状 |
| 1 | 文件名纯文本 | 保留（无障碍、tooltip、测试） |
| 2 | 目录纯文本 | 保留 |
| 3 | 大小文本 | 保留 |
| 4 | 时间文本 | 保留 |
| 5 | 行 tooltip（Pango markup） | 现状 |
| 6 | 版本标签 | 现状（`COL_TAG`） |
| **7** | **主单元格 markup**（两行：名称 + 路径） | 新 |
| **8** | **元信息单元格 markup**（两行：大小 + 时间） | 新 |

- `fill()` 里用 `core.highlight(..., 'pango')` 生成 7、8 两列；深色主题下 `mark_bg` 用 `rgba(255,201,80,0.18)` 不适用（Pango 不吃 rgba）→ 用 `#3a3320` 之类的实色底 + `#ffd98a` 前景。
- 视图：`self.view`（list of k，None 表示恒等），`count()` / `fill()` / `scroll_to()` 全部先映射。
- 行高固定 48：`measure_row_height()` 直接 `return 48, True`，`update_rows()` 里 `header = 0`（表头已隐藏）。

## 6.5 文案契约

所有新增字符串放在 `resources/strings.json`，键名即 `core.STRINGS` 与 `T` 的键名。要求：

- 每个键在 `zh` 与 `en` 都存在，`en` 不得留空、不得复制中文。
- 带变量的用 `{name}` 形式（Python `str.format`）与 JS 模板函数两种写法并列给出。
- GTK 用 `core.text(key, lang, **kw)`；Web 用 `T[lang][key]`（函数型键直接调用）。

## 6.6 可测性

- `core` 的 5 个新函数必须能在没有索引、没有 GTK 的环境下 import 并单测（不 import gi）。
- Web 侧每个新增字段都要能被 `curl` 单独验证：

```bash
curl -s "http://127.0.0.1:PORT/api/search?q=报告&page=p&type=doc&limit=3&t=TOKEN" | python3 -m json.tool
```

- GTK 侧不要求自动化，但 `fill()` 的 markup 生成必须抽成纯函数（`row_markup(...)`），可与 Web 共用同一份高亮测试。
