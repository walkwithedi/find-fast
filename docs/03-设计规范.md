# 03 · 设计规范

数值的唯一定义在 `design/tokens.css`（Web）与 `design/tokens.json`（跨端）。本文解释**为什么是这个值**以及**什么时候用哪个**。落地时只允许引用令牌，不许在组件里写死颜色与字号。

## 颜色

### 语义分层（浅色）

| 令牌 | 值 | 用在哪 | 不许用在哪 |
|---|---|---|---|
| `--surface` | `#ffffff` | 列表底、搜索框聚焦态、菜单、对话框 | 大面积页面底 |
| `--surface-2` | `#f7f9fa` | 应用条、状态栏、详情面板、输入框默认 | 行悬停（对比不够） |
| `--surface-3` | `#eef1f4` | 图标按钮按下、次级按钮悬停 | 文字底 |
| `--hover` | `#f4f7fa` | 行悬停、菜单项悬停 | 选中态 |
| `--sel` | `#eff4ff` | 选中行底 | 大面积 |
| `--ink` | `#14181d` | 文件名、标题、正文强调 | 说明文字 |
| `--ink-2` | `#4b5563` | 路径、大小、正文 | 时间戳（会与文件名抢注意力） |
| `--ink-3` | `#66717e` | 时间、说明、占位符、计数 | 任何需要被读懂的正文 |
| `--line` | `#e5e9ed` | 分隔线、chip 边框 | 输入框边框（太浅） |
| `--line-2` | `#d3dae1` | 输入框、按钮边框 | 分隔线（太重） |
| `--accent` | `#2f55d4` | 聚焦环、选中图标、链接 | 大面积填充 |
| `--accent-solid` | `#2f55d4` | 主按钮底 | 深色下同值（深色用 `#4a67e8`） |
| `--accent-ink` | `#22409e` | 选中 chip 文字、选中行文件名 | 普通正文 |
| `--accent-soft` | `#ecf0fc` | 选中 chip 底、标签底 | 行选中（用 `--sel`） |
| `--mark-bg` | `#ffe9a8` | 命中高亮底 | 整行高亮 |
| `--ico-folder` | `#9a6f16` | 文件夹图标 | 文字 |

### 对比度实测（WCAG 2.1，AA 要求正文 ≥4.5，图形 ≥3）

| 组合 | 比值 | 判定 |
|---|---|---|
| `--ink` on `--surface` | **17.8** | AAA |
| `--ink-2` on `--surface` | **7.6** | AAA |
| `--ink-3` on `--surface` | **4.97** | AA |
| `--ink-3` on `--surface-2` | **4.70** | AA |
| `--accent-ink` on `--accent-soft` | **8.03** | AAA |
| `--on-accent` on `--accent-solid` | **6.23** | AA |
| `--ink` on `--mark-bg` | **14.8** | AAA |
| `--ico-folder` on `--surface` | **4.51** | 图形 AA |
| 深色：`--ink` on `--surface` | 15.1 | AAA |
| 深色：`--ink-2` on `--surface-2` | 6.77 | AAA |
| 深色：`--ink-3` on `--surface-2` | 4.78 | AA |
| 深色：`--on-accent` on `--accent-solid` | 4.78 | AA |
| 深色：`--mark-fg` on 高亮底 | 11.4 | AAA |

> v0.6.0 的次级文字对比度约 3.0，本次调到 4.7–5.0。**不允许为了「看起来更淡」把 `--ink-3` 再调浅**。

### 深色模式规则

1. 不是把浅色反相：表面从 `#14181d` 起，越靠前的层越亮（`--surface-2` 更亮）。
2. 强调色提亮到 `#8aa2ff`，但**实心按钮底压深**到 `#4a67e8`，否则白字看不清。
3. 高亮从实色改为半透明叠加（`rgba(255,201,80,.18)` + 文字 `#ffd98a`），避免在暗底上出现刺眼的黄块。
4. 阴影只能在深色下用大扩散（`--shadow-2` 深色版），浅色下靠边框分层。
5. 切换主题不重建页面，只切 `<html data-theme>`（GTK 改 `gtk-application-prefer-dark-theme` + 重新注入 CSS）。

## 字体

| 令牌 | 值 | 用在哪 |
|---|---|---|
| `--fs-micro` | 11 | 角标（最新/有更新版）、`kbd`、状态栏键位 |
| `--fs-meta` | 11.5 | 时间、状态栏计数、chip 计数、列表末尾提示 |
| `--fs-label` | 12.5 | 路径、chip、按钮、详情正文、菜单次要项 |
| `--fs-body` | 13 | 菜单项、表单标签、详情元信息 |
| `--fs-title` | 14 | 行文件名、详情文件名 |
| `--fs-h` | 15 | 空状态标题、对话框标题 |
| `--fs-field` | 15.5 | 搜索框输入文字 |

字重只用 400 / 500 / 600：文件名 500，详情标题 600，其余 400。**不许用 700**（中文字体在 14px 下 700 会糊）。

字族：`Inter → Segoe UI → Noto Sans SC → Source Han Sans SC → PingFang SC → Microsoft YaHei`。不引外部字体文件。

## 间距

2px 基数，只允许：2 / 4 / 6 / 8 / 10 / 12 / 14 / 16 / 24 / 56。

| 场景 | 值 |
|---|---|
| 图标与文字 | 6 |
| 行内两行文本之间 | 2 |
| 搜索框内左内边距 | 12 |
| 搜索框与筛选条之间 | 10（筛选条 padding-bottom） |
| 详情面板内边距 | 16 |
| 详情面板字段行距 | 7 |
| 按钮之间 | 7 |
| 对话框内容与按钮区 | 16 |

**不用 5、9、11、13、15、18、20、32**。原型里出现的 `gap:11px`（行内列间距）统一按 11 保留——它是行栅格的一部分，写进 `--row-gap` 语义而非间距令牌。

## 圆角与描边

| 元素 | 圆角 | 描边 |
|---|---|---|
| 标签 / kbd | 4 | 1px `--line-2`，底边 2px |
| chip | 6 | 1px `--line`，选中 `--accent` 40% |
| 按钮 / 输入框 | 8 | 1px `--line-2` |
| 搜索框 | 12 | 1px，聚焦 1px `--accent` + 3px 外发光 |
| 菜单 / 对话框 | 10 | 1px `--line` + `--shadow-2` |
| 详情图标块 | 10 | 1px `--line` |

## 动效

| 场景 | 时长 | 曲线 |
|---|---|---|
| 悬停变色 | 100 | `--ease` |
| 聚焦环 | 140 | `--ease` |
| 菜单出现（opacity + translateY(-2→0)） | 120 | `--ease` |
| 折叠/展开 | 180 | `--ease` |
| 骨架 shimmer | 1400 循环 | `ease` |

只动 `opacity`、`background-color`、`color`、`transform`，不动宽高与 `top/left`（避免重排）。`prefers-reduced-motion: reduce` 时全部压到 1ms。

## 层级（z-index）

只用四档，写在 `tokens.css` 注释里：行内 0 / 粘性元素 10 / 菜单与 toast 60 / 对话框 `::backdrop`（原生）。

## 禁止清单

- 渐变、玻璃拟态、外发光（除搜索框聚焦的 3px 环）。
- 结果行做卡片（圆角 + 阴影 + 间距），行与行必须连续。
- 图标与文字基线不齐时用 `margin-top` 硬推，改用 flex `align-items:center`。
- 在 12.5px 以下使用 500 以上字重。
- 用颜色单独表达状态（必须同时有文字或图标）。
