# 04 · 组件规格

逐组件给尺寸、结构、状态、行为与平台差异。数值与 `design/web-components.css`、`prototype/find-fast-ux.html` 一致。文案键名见 `resources/strings.json`。

## 1. 应用条 AppBar（仅 Web）

高 30，底 `--surface-2`，下边框 1px `--line`，左右内边距 12。

```
[🔍 秒搜文件  0.6.0]                                    [☀] [⋯]
```

- 左：图标 15 + 名称 12.5 `--ink-2` + 版本 11.5 `--ink-3`，间距 7。
- 右：图标按钮 24×24，圆角 6，`--ink-3`；悬停底 `--surface-3` + 文字 `--ink`。
- 按钮：`外观`（日/月图标随主题切换）、`更多`（菜单：快捷键与语法、设置、收起为搜索框、关于）。
- GTK 侧**没有这一层**：用系统标题栏，把「更多」放进搜索框右侧齿轮旁边的按钮。

文案键：`app_name`、`ver`、`menu_more`、`theme`、`keys_title`、`settings`、`fold`。

## 2. 搜索框 Field

高 44，圆角 12，底 `--surface-2`，边框 1px `--line-2`，内边距 左12 右10，图标与文字间距 9。

| 状态 | 表现 |
|---|---|
| 默认 | 底 `--surface-2`，边框 `--line-2`，图标 `--ink-3`，占位符 `--ink-3` |
| 悬停 | 边框混入 40% `--ink-3` |
| 聚焦 | 底 `--surface`，边框 `--accent`，外发光 `0 0 0 3px accent/16%`，图标 `--accent` |
| 有内容 | 显示清除按钮 26×26（`i-close` 11），右侧键位提示隐藏 |
| 语法错误 | 边框 `--bad`，下方 2px 内嵌错误行（不推动布局：绝对定位在搜索框下方 24px 处，带 `--surface` 底） |

结构：`[icon 17] [input 15.5px] [kbdHint ↑↓ 选择] [clear]`。

- 输入即搜，防抖 120ms；输入法组合期间（`compositionstart`）不触发。
- `Esc`：有文字则清空；无文字则收起/隐藏窗口。
- 占位符：`搜索文件名或所在文件夹…`；折叠态用短版 `搜索…`。
- `aria-label` = 占位符全文，`role="combobox"`，`aria-controls` 指向列表，`aria-activedescendant` 指向选中行。

**扫描进度**：搜索框下缘 2px 的进度条，绝对定位（`bottom:-1px`），只在扫描时 `opacity:0→1`。不定长动画用 `translateX(-100%)→translateX(100%)` 的流动条，1.2s 循环。**不许**用会改变高度的 `Gtk.ProgressBar` 默认样式。

## 3. 筛选条 FilterBar

高 38（chip 28 + 下内边距 10），左右内边距 14，chip 间距 6。有查询且结果 >0 时才出现（否则整条 `display:none`，不留空白）。

### 3.1 类型 chip

`[标签] [计数]`，高 28，内边距 0 10，间距 6，圆角 6，字号 12.5，计数 11.5 `--ink-3` 等宽数字。

| 状态 | 底 | 边框 | 字 |
|---|---|---|---|
| 默认 | `--surface` | `--line` | `--ink-2` |
| 悬停 | `--surface-2` | `--line-2` | `--ink` |
| 选中 | `--accent-soft` | `accent` 40% | `--accent-ink`，字重 500 |
| 计数 0 | 同默认，`opacity:.45`，`pointer-events:none`，`aria-disabled="true"` | | |

顺序固定：`全部 / 文件夹 / 文档 / 图片 / 压缩包 / 代码 / 音视频 / 其他`。「其他」仅在计数 >0 时出现；其余即使为 0 也保留（位置稳定，避免跳动）。

计数**必须来自全量结果**，不是当前已加载的一页（见 `docs/06`）。

### 3.2 缩小范围（条件出现）

仅当 `全部计数 > 400` 且当前没有范围限制时出现，最多 2 个：

```
[🗀 …/图片 696] [🗀 …/文档 4]
```

- 前缀文件夹图标 12；路径用 `shortDir(dir, 2)`，即 `…/末两级`，完整路径进 `title`。
- 点击后把该目录设为 `scope`，chip 变为「已选中 + ×」，点击 × 取消。
- 选中的范围 chip 与类型 chip 同一视觉，但带 `×`（11px，`opacity:.55`，悬停 1）。

### 3.3 排序

固定在右端（`margin-left:auto`），左侧 10px 留白 + 向左的柔和投影（提示可横滑）。高 28，内边距 0 9，间距 6。

`[⇅ 最新在前 ▾]` → 点击弹菜单，7 项，当前项打勾：

`最新在前 / 最旧在前 / 名称 A→Z / 名称 Z→A / 最大在前 / 最小在前 / 路径 A→Z`

## 4. 结果行 Row

### 4.1 解剖

```
┌─15─┬20┬11┬────────────── 1fr ──────────────┬11┬─116─┬12─┐
│    │🗎 │  │ 报告（第27期）.pdf        [最新]  │  │2.28 MB│   │  48
│    │  │  │ …/项目甲                                │  │3 小时前│   │
└────┴──┴──┴─────────────────────────────────┴──┴──────┴───┘
```

| 元素 | 规格 |
|---|---|
| 行高 | 48（固定，`--row-h`） |
| 栅格 | `20px minmax(0,1fr) 116px`，gap 11，内边距 `0 12 0 15` |
| 类型图标 | 17×17，居中；默认 `--ink-3`，文件夹 `--ico-folder` |
| 文件名 | 14 / 500，`--ink`，单行省略 |
| 路径 | 12.5，单行省略；末级目录 `--ink-2`，上级 `--ink-3`，分隔符 `/` `--ink-3` 70% |
| 两行间距 | 2 |
| 元信息 | 右对齐，纵向：大小 12.5 `--ink-2`，时间 11.5 `--ink-3`，均等宽数字，间距 2 |
| 标签 | 11，内边距 0 5，圆角 4，`--line-2` 边框，`--ink-3`；「最新」用 `--accent-soft` 底 + `--accent-ink` |

路径显示规则（`core.short_dir`）：若 `dir` 以 `$HOME` 开头先缩写为 `~`；随后若段数 >3，只显示 `…/末两级`；末级即文件所在目录（不含文件名）。示例：`/home/u/文档/项目甲` → `~/文档/项目甲`；`/root/proxy/data/logs` → `…/data/logs`。高亮区间必须基于**缩写后**的字符串计算。 <!-- sensitive-scan: ignore -->

### 4.2 状态

| 状态 | 表现 |
|---|---|
| 默认 | 透明 |
| 悬停 | 底 `--hover` |
| 选中 | 底 `--sel`，左侧 3px `--sel-line`（上下各缩进 8px，右侧圆角 3），文件名 `--accent-ink`，路径与时间提到 `--ink-2` |
| 按下 | 同选中 |
| 键盘焦点 | 焦点在列表容器上时 `outline:2px solid --accent; outline-offset:-2px`；行本身不加 outline（避免逐行抖动） |

### 4.3 命中高亮

- 服务端返回的 `name_html` / `dir_html`，命中处 `<mark>`（GTK 为 `<span background>`）。
- 只标**正向**查询词；`!排除词` 不标。
- 名称里标到的词不再在路径里重复标（同一词优先名称）。
- 最多 24 段；相邻/重叠区间合并。
- 高亮只作用于当前渲染的行（≤200 行 Web，≤60 行 GTK），**不许**对全量结果预先计算。

### 4.4 行为

| 操作 | 结果 |
|---|---|
| 单击 | 选中（不打开），详情面板更新 |
| 双击 | 打开 |
| 右键 / `Menu` 键 / `Shift+F10` | 选中并弹出上下文菜单（见 9） |
| 拖拽（GTK） | 拖出 `text/uri-list`，可拖到文件管理器 |

## 5. 列表容器

- `role="listbox"`，`aria-label="搜索结果"`，`tabindex="0"`，子项 `role="option"` + `aria-selected`。
- 分页：首屏 200 行，滚动到距底 20 行时追加 200 行（Web）；GTK 保持「store 只装可见行」的虚拟化。
- 列表末尾（结果全部渲染完）：一行居中提示 `已显示全部 N 个结果`，11.5 `--ink-3`，上内边距 16 / 下 24，`role="presentation"`。
- 空列表时显示空状态（见 8），空状态覆盖列表区而非替换容器。
- 滚动条宽 11，滑块 `--line-2`，3px 透明边框做内缩，悬停 `--ink-3`；`scrollbar-gutter:stable` 防抖动。

## 6. 详情面板 Preview

### 6.1 未选中（仅空状态时出现）

显示索引信息卡：条目数、文件夹数、索引时间、监听状态、唤起键提示。**不显示**「选中一条结果」这种废话。

## 7. 状态栏 StatusBar

高 28，底 `--surface-2`，上边框 1px `--line`，内边距 0 14，字号 11.5，等宽数字。

```
7,204 个结果 · 12 毫秒        ↑↓ 选择  Enter 打开  Ctrl Enter 定位  ? 快捷键        ● 实时更新 · 共 128,441 项
```

| 区 | 内容 | 规则 |
|---|---|---|
| 左 | `N 个结果 · X 毫秒` | 数字 600 字重 `--ink`，单位 `--ink-2`；无查询时显示 `就绪` |
| 中 | 键位提示 | 宽度 <860 隐藏 |
| 右 | `● 状态 · 共 N 项` | 圆点 6px，`--ok`；异常时 `--warn`/`--bad` 并改文案 |

规则：
- **只有这一处报数**。筛选条 chip 上的分类计数不算重复（不同维度）。
- 扫描中：左侧改为 `正在更新索引：N 个文件夹，M 个条目`，右侧保留上次的条目数。
- 错误消息 5 秒后自动退回常态，不阻塞操作。

## 8. 空状态 EmptyState

三种，都在列表区内（覆盖，不替换），垂直起始位置 `11vh`，内容最大宽 460，居中。

### 8.1 起始（无查询）

```
        [🔍 52]
     找一个文件
  输入文件名，或文件名的一部分。
  词也可以落在文件夹名上。

  [报告]  [ext:pdf;docx]  [path:2026]
```

- 标题 15/600；说明 13 `--ink-2`，行高 1.7；示例按钮 12.5，内边距 5 9，圆角 6。
- 示例按钮点击后填入搜索框并立即搜索（`aria-label="搜索 报告"`）。
- 右侧详情面板同时显示索引信息卡。

### 8.2 无匹配

```
        [⊘ 52]
     没有匹配「zzzz」的结果
  试试去掉类型筛选，或用一个更短的词。

  [清除搜索]  [查看语法]
```

- 标题里回显查询词（超过 24 字截断加省略号）。
- 若有类型筛选/范围限制，说明改为 `当前有类型筛选：文档（5）`，并给「取消筛选」按钮。

### 8.3 索引未就绪

6 行骨架（行高 48，两行灰条 12/10，shimmer 1.4s），状态栏显示 `正在载入索引……`。**不显示**空状态文字，避免和「无结果」混淆。

## 10. 对话框

宽 720，最大高 82vh，圆角 12，`--shadow-2`，标题 15/600，内边距 16；内容区滚动，底部按钮区固定（56 高，右对齐，间距 8）。

### 10.1 快捷键与语法

两列：左列「键位」，右列「语法」。语法项可点击，点击后关闭对话框并把示例填入搜索框。

### 10.2 设置

左侧分区导航 168（`索引的文件夹 / 排除规则 / 搜索 / 升级`），右侧内容区。当前分区 `--accent-soft` 底 + `--accent-ink` 字。底部固定 `恢复默认 ····· 取消 保存`。

- 「列顺序」分区**删除**（两行行结构下无意义）。
- GTK 允许用 `Gtk.StackSwitcher` 代替左侧导航（原生、可访问），但分区必须一致。

## 12. 折叠态 LauncherBar

高 90，圆角 0，底 `--surface`，只有一行搜索框（垂直居中）+ 右侧 `共 N 项`（11.5 `--ink-3`）。

- 展开条件：有文字 / 用户点「展开」/ 全局快捷键再次触发。
- 收起条件：文字清空后 300ms，或 `Esc`（空文字时），或菜单「收起」。
- 收起时窗口宽度、位置不变，只改高度（GTK：`resize(w, 90)`；**不许**用 1px + WM 兜底）。
- 折叠态必须能完成「输入 → ↓ → Enter」全流程，不需要先展开。
