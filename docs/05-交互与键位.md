# 05 · 交互与键位

原则：**手不离键盘能走完全程**，鼠标是加速器而不是必需品。任何需要「先点一下某处」才能继续的操作都算缺陷。

## 键位表

### 全局（GTK 与 Web 页面都有焦点时）

| 键 | 动作 | 备注 |
|---|---|---|
| `Ctrl Alt Space` | 显示 / 隐藏窗口 | GTK 专有，可配置，Web 无 |
| `Esc` | 逐级退出：清空搜索 → 收起列表 → 隐藏窗口 | 有对话框/菜单时先关它们 |
| `F5` | 重新扫描 | 扫描中按下给提示，不排队 |
| `Ctrl ,` | 设置 | 与多数 GNOME 应用一致 |
| `?` | 快捷键与语法面板 | 搜索框为空时才触发，否则输入问号 |

### 搜索框内

| 键 | 动作 |
|---|---|
| `↓` / `↑` | 选中下 / 上一条（到边界不循环） |
| `PgDn` / `PgUp` | ±8 条 |
| `Home` / `End` | 首条 / 末条（仅当光标在文本首/尾，避免抢文本编辑按键） |
| `Enter` | 打开选中项（无选中则打开第一条） |
| `Ctrl Enter` | 在文件管理器中定位 |
| `Ctrl C` | 复制文件（有文本选中时复制文本；Web 端仅复制文本） |
| `Ctrl Shift C` | 复制完整路径 |
| `Tab` | 到筛选条；`Shift Tab` 回应用条按钮 |
| `Ctrl A` | 全选搜索文本（原生行为，不拦截） |

### 列表内（焦点在 `#rows`）

| 键 | 动作 |
|---|---|
| `↑` `↓` `PgUp` `PgDn` `Home` `End` | 移动选中 |
| `Enter` | 打开 |
| `Esc` | 焦点回搜索框（不清空） |
| `Menu` / `Shift F10` | 上下文菜单，锚定选中行 |
| 任意可打印字符 | 焦点跳回搜索框并把该字符追加到查询（type-ahead），不丢输入 |

### 对话框

| 键 | 动作 |
|---|---|
| `Esc` | 关闭，焦点回到打开它的控件 |
| `Enter` | 主按钮（保存 / 确定）；在 textarea 内不触发 |
| `Tab` / `Shift Tab` | 在对话框内循环，不逃逸到背景 |
| `Ctrl Enter` | 同主按钮（长表单里更顺手） |

## 鼠标

| 操作 | 结果 |
|---|---|
| 单击行 | 选中 + 更新详情（不打开） |
| 双击行 | 打开 |
| 右键行 | 选中 + 上下文菜单 |
| 滚轮 | 滚动列表；`Ctrl 滚轮` 不改字号（不做缩放） |
| 拖拽行（GTK） | 拖出 `text/uri-list`，可落到文件管理器 / 聊天窗口 |
| 单击 chip | 切换该类型筛选（再点一次回「全部」） |
| 单击范围 chip 的 `×` | 取消范围限制 |
| 单击排序 | 弹菜单 |
| 单击路径框右侧图标 | 复制完整路径，toast 确认 |
| 单击示例 chip | 填入搜索框并立即搜索 |
| 点击菜单外 | 关闭菜单，不改变选中 |

## 焦点流

```
[全局快捷键] → 搜索框（autofocus，文本全选）
      ↓ Tab
   筛选条（roving tabindex：只有选中的 chip 可 Tab 到，←→ 切换）
      ↓ Tab
   排序按钮 → 列表容器（↑↓ 在内部移动）→ 详情面板按钮 → 状态栏
      ↑ Shift+Tab 反向
```

规则：
- 打开窗口时焦点**永远**在搜索框，且已有文字全选（用户可以直接改写上次的查询）。
- 打开对话框前记录来源控件，关闭后焦点还给它。
- 菜单关闭后焦点回到搜索框（不是回到行，避免用户以为要重新选）。
- 选中状态用 `aria-activedescendant` 表达，**不移动 DOM 焦点**，这样用户边输入边用 ↓ 不会丢输入。

## 反馈时序

| 事件 | 反馈 | 时长 |
|---|---|---|
| 输入 | 结果区即时刷新（防抖 120ms） | ≤120ms |
| 选中 | 行高亮 + 详情更新 | 同帧 |
| 打开 | toast `已打开：文件名` | 2.2s |
| 定位 | toast `已在文件管理器中打开所在文件夹` | 2.2s |
| 复制 | toast `已复制路径：…`（超长截断） | 2.2s |
| 排除 | toast `已排除：…`，结果行立即消失 | 2.2s |
| 扫描 | 2px 流动条 + 状态栏文字变化 | 全程 |
| 错误 | 就地错误行（语法）/ 状态栏 `--bad` 文案 | 5s 后回常态 |

## 平台差异（必须按平台分支，不许假装一致）

| 能力 | GTK | Web |
|---|---|---|
| 复制文件到剪贴板 | ✅（`text/uri-list`） | ❌ 只有复制路径 |
| 拖出行到文件管理器 | ✅ | ❌ |
| 全局唤起键 | ✅ | ❌ |
| 收起为浮条 | ✅ 窗口高度 90 | ✅ CSS 折叠（仅演示，真实场景无意义） |
| 多窗口 | 单实例 | 单标签页 |
| 打开文件 | `Gio.AppInfo` | 服务端 `/api/open` |

## 不许做的事

- `Esc` 直接退出程序。用户按 Esc 是想「退一步」，不是想关工具。
- 输入时选中项重置到第一行却不给视觉提示。重置必须伴随列表滚动到顶部。
- 双击打开的同时也触发两次单击选中（用 `mousedown` 选中 + `dblclick` 打开，阻止默认）。
- 阻止 `Ctrl+C` 的默认复制行为（有文本选中时必须让浏览器/GTK 复制文本）。
- 用 `keypress` 监听（用 `keydown`，且判断 `isComposing`）。
