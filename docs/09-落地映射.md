## 2. `find_fast_web.py`

### `Service.search()`（约 294 行）

现签名 `search(self, page, query, sort, desc, regex)`。改为：

```python
def search(self, page, query, sort, desc, regex, type_='all', scope='', reuse_sid=''):
    ...
    with self.lock:
        got = self.results.get(page)
    if reuse_sid and got is not None and got[0] == reuse_sid and (query, sort, desc, regex) == got[2]['key']:
        res = got[1]
        n = len(res)
        holder = got[2]
        holder['view'] = build_view(res, n, type_, scope)
        return reuse_sid, res, view_count(res, holder)
    # 否则照旧执行 index.search，holder 里多存 key / facets / view
```

`holder` 初始化为：

```python
holder = {'key': (query, sort, desc, regex), 'groups': None,
          'facets': None, 'view': None}
```

- `build_view` / `facets_of` 写成模块级函数（可单测），不要塞进类里。
- facets 在 `n <= 200_000` 时同步算；否则 `holder['facets'] = None`，并在 `/api/rows` 或新增的轻量参数里补算（见 `docs/06` 6.3）。
- `scope_suggest` 同样随 facets 缓存。

view = got[2].get('view')

## 6. 十二个陷阱

1. **`#rows.children[k]` 被末尾提示挤歪** → 提示放 `#listEnd`（兄弟节点）。
2. **`aria-activedescendant` 指向不存在的 id**（分页后旧行被替换）→ 每次 `paintSel()` 重设。
3. **GTK `dim_tags()` 依赖已删除的 `tag_cell`** → 标签进 markup，删除 `dim_tags` 及其 `style-updated` 连接。
4. **`update_rows()` 仍在取表头高度** → 表头隐藏后 `get_button()` 返回 None，直接 `//48`。
5. **`select()` 里 `if (focus) tr.scrollIntoView()`** → 改成 `block:'nearest'`，否则每按一次 ↓ 都跳到视口中线。
6. **把 `type` 过滤做在前端** → 计数只统计已加载的 200 行，与实际差几十倍。必须服务端。
7. **复用 sid 时忘了校验 query/sort** → 切排序后拿到旧结果。
8. **`highlight()` 在转义前切分** → 文件名含 `<` 时生成坏 HTML（XSS 风险）。
9. **Pango markup 里用 `&` 未转义** → 整行不显示（GTK 会静默失败）。
10. **深色下沿用 `#ffe9a8` 高亮底** → 刺眼且与白字对比不足，用 `#3a3320` 底 + `#ffd98a` 字。
11. **`Ctrl+C` 拦截了文本选择复制** → 有 `selectionStart !== selectionEnd` 时放行。
12. **删除 `<h1>` 后忘了 `applyLanguage` 里对 `#title` 的引用** → 控制台报 null。
