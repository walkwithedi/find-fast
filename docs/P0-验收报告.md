## 验证

- Python 全部文件编译通过。
- 系统 Python + GTK3 + 虚拟显示：unittest 全套 177 项通过，包含百万条结果滚动与排序、GTK 升级回退。
- 无显示的 pytest：134 passed、43 skipped（GTK 用上述独立运行覆盖）、11 subtests passed。打包原测试采用标准库 unittest，无需新增测试或运行时依赖。
- node tests/web.test.js：通过；覆盖搜索、设置与持久化、键盘打开与定位、复制路径、排除、版本跳转、分页、明暗持久化、窄窗口与退出。
- node tests/upgrade.test.js：通过；覆盖升级检查、执行、重新连接与回退。
- scripts/run_checks.py：测试、仓库结构与敏感信息扫描通过。规格文档中的虚构示例路径已按维护者确认逐行标记扫描豁免。
- 原有 core 函数和类经 AST 比较均未改变；tool_upgrade.py、upgrade-keep.txt、TOOL_UPGRADE_VERSION、find_fast.py 与唤起键实现未改。
- 200 行高亮耗时中位约 1.00ms。GTK 百万条结果的滚动与 End 跳转约 14–22ms，排序约 3ms；这不等同于全端到端性能认证。
- 对比度实算：浅色正文 17.82、次文字 7.56、弱文字在次表面 4.70、强调文字 8.03、主按钮 6.23；深色正文 15.13、弱文字在次表面 4.78、主按钮 4.78。

## 保留检查与边界

- 未在真实麒麟桌面与其他 GTK 主题逐一做视觉检查；自动化运行使用 GTK3 虚拟显示。
- 万条结果端到端增量耗时、十万条结果滚动帧率尚未单独测量，后者属于 T12。
- 类型芯片的主题联动随 T06 验收。
- GTK 原生 TreeView 的选中背景已使用令牌，左侧 3px 标记的跨主题外观仍需人工复核。
- P1/P2：类型收敛、空状态、快捷键/语法面板、设置重排、折叠重做与完整响应式仍未开始。
- GTK 输出包含虚拟会话注册警告，所有断言通过；真实窗口管理器中的焦点表现仍需人工复核。
