# find-fast 设计规格（0.1.0）

## 一、定位

Linux 上的全盘文件名秒搜工具，中文名「秒搜文件」。第一版只搜文件名和路径，不搜文件内容，不接 AI。

## 二、代码来源与仓库

1. 以 walkwithedi/ask-local-files 的索引代码为起点（扫描、按目录修改时间增量、路径拼成字符串后用 str.find 查找），一次性复制，之后各自演进。
2. 本仓库为母版；转为公开前用 `scripts/sensitive_scan.py --history` 扫描全部历史。
3. 许可证 MIT。
4. 敏感信息防护：`scripts/sensitive_scan.py`、`.claude/hooks`、`.githooks`、checks、sensitive-history、sensitive-text 工作流，仓库 Secret `SENSITIVE_TERMS`。

## 三、技术栈与平台

1. Python 3.8+ 标准库，加系统自带的 GTK3（PyGObject，python3-gi）；不用 pip，不编译。
2. 目标系统麒麟、Ubuntu；架构 x86_64、arm64。
3. 没有 python3-gi 时，用 zenity 或 notify-send 提示，退回本机网页。
4. 核心模块（索引、搜索）与 GTK、网页两套界面分开；另带命令行查询。

## 四、运行方式

1. 用时启动，关窗即退出，不常驻。Gtk.Application 保证单实例：已在运行时再次启动，激活已有窗口。
2. 启动后马上载入紧凑二进制缓存即可搜索；后台按目录修改时间增量补扫，状态栏显示进度。
3. 窗口开着时用 inotify 实时更新（ctypes），后台建立监听；监听数超过 max_user_watches 时，超出部分退回定时扫描。
4. 全局快捷键：提供唤出命令，由使用者在系统快捷键里绑定，README 写明步骤。

## 五、索引范围

1. 默认：家目录，以及 /media、/mnt 下的本地文件系统。
2. 不包括：网络挂载（nfs、cifs、smb、sshfs 等）、伪文件系统（/proc、/sys 等）、系统目录。
3. 默认跳过点号开头的隐藏项，可以打开；目录与排除规则可增减（`~/.config/find-fast/config.json`）。
4. 设计规模：百万级文件；两三百万条仍可用。

## 六、功能

1. 搜索语法：多个词同时匹配（不区分大小写）、正则表达式、通配符 `*` `?`、`!` 排除、`|` 表示或、`path:` 匹配完整路径、`ext:` 按扩展名过滤。按大小、日期过滤留到第二版。
2. GTK 结果列表：名称、路径、大小、修改时间四列，点列头排序（默认最新在前）；只渲染可见行，不限制结果条数；回车打开；右键打开、打开所在文件夹、复制路径；可拖到其他程序。
3. 界面中英双语，按 `LANG` 选择；文字集中在一个字典里，不用 gettext。
4. 网页退回：搜索、结果表、打开、打开所在文件夹、复制路径。

## 七、本机服务约定（网页退回）

1. 只监听 127.0.0.1 的随机端口；令牌每次启动随机生成，进程运行期间有效，退出即作废；校验 Host、Origin。
2. 页面关闭或刷新时用 sendBeacon 通知，全部页面关闭数秒后退出；心跳超时只作兜底；有任务进行时等任务结束再退出。
3. 打不开浏览器或缺少页面文件时用 zenity、notify-send 提示。
4. 界面是独立 .html 文件，不从网络加载资源。

## 八、界面与文案约定

见 `CLAUDE.md` 的「交互界面约定」与「Python 脚本日志约定」。

## 九、性能验收线

在 CI 的 ubuntu 运行器上，用 `scripts/bench.py` 造一百万条路径测量：

- 冷启动（读缓存到可搜）不超过 1 秒；
- 单次搜索不超过 100 毫秒；
- 进程常驻内存不超过 300 MB。
