# find-fast 设计规格（0.2.0）

## 一、定位

Linux 上的全盘文件名秒搜工具，中文名「秒搜文件」。第一版只搜文件名和路径，不搜文件内容，不接 AI。

## 二、代码来源与仓库

1. 以 walkwithedi/ask-local-files 的索引代码为起点（扫描、按目录修改时间增量、路径拼成字符串后用 str.find 查找），一次性复制，之后各自演进。
2. 本仓库为母版；转为公开前用 `scripts/sensitive_scan.py --history` 扫描全部历史。
3. 许可证 MIT。
4. 敏感信息防护：`scripts/sensitive_scan.py`、`.claude/hooks`、`.githooks`、checks、sensitive-history、sensitive-text 工作流，仓库 Secret `SENSITIVE_TERMS`。

## 三、技术栈与平台

1. Python 3.8+ 标准库，加系统自带的 GTK3（PyGObject，python3-gi）；不用 pip，不编译。
2. 目标系统麒麟、Ubuntu；架构 x86_64、arm64。
3. 没有 python3-gi 时，用 zenity 或 notify-send 提示，退回本机网页。
4. 核心模块（索引、搜索）与 GTK、网页两套界面分开；另带命令行查询。

## 四、运行方式

1. 用时启动，关窗即退出，不常驻。Gtk.Application 保证单实例：已在运行时再次启动，激活已有窗口。
2. 启动后马上载入紧凑二进制缓存即可搜索；后台按目录修改时间增量补扫，状态栏显示进度。
3. 窗口开着时用 inotify 实时更新（ctypes），后台建立监听；监听数超过 max_user_watches 时，超出部分退回定时扫描。
4. 全局快捷键：在设置里录入后，用 gsettings 写入桌面的自定义快捷键（UKUI：org.ukui.control-center.keybinding，路径 /org/ukui/desktop/keybindings/find-fast/；GNOME：media-keys 的 custom-keybindings，路径 …/custom-keybindings/find-fast/），只增改本工具那一条；命令为 `find-fast --toggle`（已用 install.sh 安装时）或 `python3 <目录>/find_fast.py --toggle`。--toggle 由已运行的实例处理：在前台则隐藏（索引照常更新），否则调到前台并全选搜索框。识别不了桌面时只给出命令供手动绑定。默认唤起键 Ctrl+Alt+Space：`install.sh` 调用 `--default-hotkey` 时写入（并把已设的唤起键改指向安装后的命令），未安装时首次启动（窗口或网页）写入；只在 config.json 的 keys 里从未有过 toggle 时写一次，写后记 `toggle_default_done`；该键已被桌面占用、识别不了桌面或写入出错时不写，并说明原因。窗口内快捷键存于 config.json 的 keys。`--remove-hotkey`（install.sh --uninstall 调用）删除写入的那一条。

## 五、索引范围

1. 默认：家目录，以及 /media、/mnt 下的本地文件系统。
2. 不包括：网络挂载（nfs、cifs、smb、sshfs 等）、伪文件系统（/proc、/sys 等）、系统目录。
3. 默认跳过点号开头的隐藏项，可以打开；目录与排除规则可增减（`~/.config/find-fast/config.json`）。
4. 窗口与网页都有「设置」（搜索框右侧齿轮按钮）：增删索引的文件夹与排除规则（选文件夹或写名称规则）、隐藏开关、恢复默认。保存前检查：文件夹为空不能保存；不存在、在网络挂载上、互相包含、排除不在范围内的先列出原因，可「仍然保存」；重复项合并，家目录下写成 `~/`。保存后立即在后台更新索引：只新增排除时在内存中剔除命中条目（不访问磁盘），其余改动增量重扫（复用的目录列表同样按新规则过滤），打开隐藏项或删除排除时全量重扫；正在扫描时先停止再开始。
5. 结果右键可排除：文件夹行排除它自己，文件行排除所在文件夹；确认后写入设置；索引根目录本身不提供此项。
6. 设计规模：百万级文件；两三百万条仍可用。

## 六、功能

1. 搜索语法：多个词同时匹配（不区分大小写；普通词按完整路径匹配，可在文件名或任一层文件夹名里，设置 `match_path` 可关；通配、`ext:`、`regex:` 只看文件名）、正则表达式、通配符 `*` `?`、`!` 排除、`|` 表示或、`path:` 匹配完整路径、`ext:` 按扩展名过滤。按大小、日期过滤留到第二版。
2. 类似版本：在当前结果内按文件名归组（规则集中在 `find_fast_core.py` 的 VERSION_MARKS：副本标记、开头序号、首尾日期、版本号、稿件词，再忽略大小写、全半角、空格与括号，扩展名须相同，去标记后少于 2 个字不归组；文件夹不参与）。组内修改时间最新者（同时取路径较短）标「最新」，其余标「有更新版」；悬停追加同组数量与最新路径；右键「跳到最新版」。超过 100000 条不分组并在状态栏写明，5000 条以上后台计算。
3. GTK 结果列表：名称、路径、大小、修改时间四列，点列头排序（默认最新在前），拖动列头或在设置里上移、下移调整列顺序（定位列固定在最后，顺序存入界面状态；网页存于浏览器本地存储）；只渲染可见行，不限制结果条数；第五列为定位按钮；回车打开，Ctrl+Enter 定位，Ctrl+C 复制文件（剪贴板同时提供 x-special/gnome-copied-files、text/uri-list 与路径文本），Ctrl+Shift+C 复制路径；右键依次为定位、打开、复制文件、复制路径，分隔线后为跳到最新版、排除、重新扫描；可拖到其他程序；悬停结果行提示完整路径。
4. GTK 窗口在搜索框为空时只显示搜索框一行（原位置变矮、宽度不变），输入即展开到记住的高度，无结果也展开并显示「没有找到」；最大化时不收起；收起时搜索框右侧小字显示索引状态与临时提示，版本号在悬停说明中；收起时的高度不写入界面状态。
5. GTK 窗口紧凑排布（单元格上下边距约 1px，字体与颜色跟随系统）；失焦时整窗 70% 不透明（需合成器，本窗口菜单与对话框不算失焦）；列宽、窗口大小、最大化、位置（Wayland 下与离开显示器时不恢复）与排序存于 `~/.config/find-fast/ui-state.json`（600），关窗时写入，坏值回退默认。网页不受影响。
6. 界面中英双语，按 `LANG` 选择；文字集中在一个字典里，不用 gettext。
7. 网页退回：搜索、结果表（行末定位按钮）、打开、定位、复制路径（不提供复制文件，Ctrl+C 仍复制路径）、设置、右键菜单；「添加文件夹……」用 zenity，没有时改为输入路径。

8. 原地升级：用 `tool_upgrade.py`（共用升级模块的原样副本，来源版本写在 `TOOL_UPGRADE_VERSION`，本仓不修改）在原位置替换工具目录，路径不变，桌面链接、`install.sh` 的菜单项与唤起键不受影响。入口：GTK 设置「升级」一节（从 zip 升级、从解压好的目录升级、退回上一版）、网页「升级」面板、命令行 `--upgrade ZIP|DIR`（`--yes`）与 `--rollback`。检查结果写明「当前版本 → 新版本」、两版之间 CHANGELOG 的各条、会保留与多出来的文件，降级或重装另外说明；确认按钮「升级到 vX.Y.Z」。检查与替换在后台线程进行，状态栏显示阶段文字，搜索框可用；完成后窗口以新版重新执行本程序（等会话总线上的旧名称释放后再登记），网页服务以同一端口与令牌重新执行，页面轮询到新服务后刷新。保留清单 `upgrade-keep.txt` 为空（设置与索引在工具目录外）；多出来的文件不删除，随旧目录留在 `.find-fast.上一版`。拒绝条件与失败恢复见升级模块的说明；网页上传的 zip 只写系统临时目录，新接口校验令牌、Host、Origin。

## 七、本机服务约定（网页退回）

1. 只监听 127.0.0.1 的随机端口；令牌每次启动随机生成，进程运行期间有效，退出即作废；校验 Host、Origin。升级或退回后同一进程以新版重新执行，沿用原端口与令牌。
2. 页面关闭或刷新时用 sendBeacon 通知，全部页面关闭数秒后退出；心跳超时只作兜底；有任务进行时等任务结束再退出。
3. 打不开浏览器或缺少页面文件时用 zenity、notify-send 提示。
4. 界面是独立 .html 文件，不从网络加载资源。

## 八、界面与文案约定

见 `CLAUDE.md` 的「交互界面约定」与「Python 脚本日志约定」。

## 九、性能验收线

在 CI 的 ubuntu 运行器上，用 `scripts/bench.py` 造一百万条路径测量：

- 冷启动（读缓存到可搜）不超过 1 秒；
- 单次搜索不超过 100 毫秒；
- 进程常驻内存不超过 300 MB。
