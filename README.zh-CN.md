# 秒搜文件（find-fast）

[English](README.md)

在 Linux 桌面上按文件名秒搜家目录和本地磁盘里的文件，边输入边出结果。只需要 Python 3 和大多数 Linux 桌面自带的 GTK3 绑定（python3-gi）；没有时改用浏览器打开同样的搜索页面。

- 免安装：Python 3.8 及以上的标准库加系统自带的 PyGObject，不用 pip，不用编译，运行时不访问网络。
- 快：索引以紧凑格式存在磁盘上，打开窗口约 1 秒内即可搜索，后台补扫关窗期间的变化；窗口开着时用 inotify 实时更新。
- 结果不限条数：列表只绘制屏幕上看得到的行，一百万条结果也能滚动、排序。
- 只搜文件名和路径，不搜文件内容。
- 界面中英双语，跟随 `LANG`。

## 目录内容

| 文件 | 作用 |
| --- | --- |
| `秒搜文件.desktop` | 双击入口，显示为「秒搜文件」。 |
| `install.sh` | 可选安装：装到 `~/.local`，加命令 `find-fast` 和应用菜单项。 |
| `find_fast.py` | 入口：不带参数打开窗口，带查询词时在终端输出结果。 |
| `find_fast_core.py` | 索引与搜索：扫描、缓存、查询语法、inotify。 |
| `find_fast_gtk.py` | GTK3 窗口。 |
| `find_fast_web.py`、`find_fast.html` | 浏览器页面（没有 python3-gi 时使用）。 |
| `tests/`、`scripts/`、`docs/` | 开发用：测试、检查与基准脚本、规格（发行包里不含）。 |

## 运行环境

- Linux 桌面（麒麟、Ubuntu 等），x86_64 或 arm64。
- Python 3.8 或更新版本。
- 窗口版需要 python3-gi 和 GTK 3 运行库（`import gi` 能成功即可；Ubuntu、麒麟桌面一般已预装）。没有时自动改用浏览器页面并提示。
- 可选：`xdg-open`（打开文件）、`gdbus`（网页版在文件管理器里选中文件）、`zenity` 或 `notify-send`（没有终端时的提示）。

## 使用方法

从 Releases 下载 `find-fast-v<版本>.zip` 解压，双击 `秒搜文件.desktop`；或在终端运行 `python3 find_fast.py`。桌面上可以放它的链接（在文件管理器里右键它，选「发送到桌面快捷方式」），不要复制（复制后找不到同目录的程序）。0.4.0 起入口由 `双击运行.desktop` 改名为 `秒搜文件.desktop`，与其他工具的入口不再重名；之前放在桌面的旧链接会失效，需从工具目录重新「发送到桌面快捷方式」。

想从应用菜单打开，运行一次 `bash install.sh`。它把工具复制到 `~/.local/share/find-fast`，建立命令 `~/.local/bin/find-fast` 和菜单项「秒搜文件」，并写入默认唤起快捷键 Ctrl+Alt+Space（见下文「全局快捷键」），不需要 root。`bash install.sh --uninstall` 卸载，设置和索引保留。

第一次打开会建立索引，状态栏显示进度，期间已经可以搜索已扫到的部分。之后每次打开先载入上次的索引，后台只重新列出有变化的文件夹。

### 全局快捷键

默认唤起快捷键是 Ctrl+Alt+Space：运行 `install.sh` 时写入，所以装好后不用先打开工具，按下就能拉起窗口；没有安装、直接从解压的目录运行的，第一次启动时写入。只在从没设置过时写这一次：之后改过或清除过，不会再被改回来。Ctrl+Alt+Space 已被桌面别的快捷键占用、识别不了桌面或写入出错时不写，安装输出和窗口状态栏（网页版在状态区）写明原因，请到「设置」里自己设一个。

在窗口的「设置」→「快捷键」→「唤起或隐藏窗口」里修改：点按钮后按下组合键即可。保存时写入桌面自己的自定义快捷键（麒麟 UKUI 或 GNOME，通过 gsettings），在系统设置里也能看到；它执行 `find-fast --toggle`：窗口在前台时隐藏，否则调到前台并全选搜索框里的文字，没有运行时直接启动。隐藏后程序继续在后台运行，索引照常更新；点关窗按钮，或在空搜索框里再按一次 Esc，才退出。录入的组合键已被桌面别的快捷键占用时，会先写明被哪个占用，确认后可「仍然保存」。清除这项，或运行 `bash install.sh --uninstall`，只删除本工具写入的那一条。

没有用 `install.sh` 安装时，快捷键指向解压出来的目录（`python3 <工具目录>/find_fast.py --toggle`），移动目录后要重新设置。识别不了桌面或没有 gsettings 时不写入，设置里会给出要绑定的命令和「复制命令」按钮，请手动添加：

- GNOME（Ubuntu）：设置 → 键盘 → 查看及自定义快捷键 → 自定义快捷键 → 添加，命令填 `/home/<用户名>/.local/bin/find-fast --toggle`。
- 麒麟（UKUI）：设置 → 设备 → 快捷键 → 自定义快捷键 → 添加，程序填同样的命令。

窗口内的快捷键也在这一栏：定位、打开所选（回车始终可用）、复制文件、复制路径、打开设置、重新扫描、聚焦搜索框。方向键、回车、Esc 固定，不能录入；快捷键须带 Ctrl、Alt 或 Super，或用 F1 至 F12；两个动作设成同一组合键时不能保存。修改后立即生效，不会重建索引；「恢复默认」改回下文「窗口操作」里的默认键位，唤起快捷键改回 Ctrl+Alt+Space。

### 搜索语法

| 写法 | 含义 |
| --- | --- |
| `report 2024` | 路径里同时含有这几个词（不分大小写）：每个词可以在文件名里，也可以在所在的任一层文件夹名里 |
| `pdf\|docx` | 含有任一个 |
| `!draft` | 不含 |
| `*.pdf`、`img_??.png` | 通配符，匹配整个文件名 |
| `ext:pdf;docx` | 按扩展名 |
| `path:project`、`docs/2024` | 匹配完整路径（带 `/` 的词自动按路径匹配） |
| `regex:^img_\d+` | 正则表达式（匹配名称，不分大小写） |
| `"annual report"` | 引号内的空格算词的一部分 |

文件夹本身也会出现在结果里。

普通词按完整路径匹配：`项目甲 28期` 能找到 `~/文档/项目甲/报告（第28期）.pdf`；`!draft` 排除路径里任何一处含 draft 的条目。路径包括索引的文件夹本身（如家目录 `/home/<用户名>`），所以搜这几级文件夹名里的词会命中其下全部条目。通配符、`ext:`、`regex:` 和「正则」模式仍只看文件名。想只搜文件名，在「设置」里关掉「搜索词也匹配路径」。

### 窗口操作

- 输入即搜；↓ 进入列表，在第一行按 ↑ 回到搜索框；在列表里直接打字会回到搜索框继续输入。
- ↑ ↓、Page Up、Page Down、Home、End 选择；回车或双击打开；Ctrl+Enter 定位；Ctrl+C 复制文件；Ctrl+Shift+C 复制路径。以上为默认键位，可在「设置」里修改，见上文「全局快捷键」。
- 定位：在文件管理器中打开所在文件夹并选中该项（文件和文件夹都适用）；文件管理器不支持选中时只打开文件夹，状态栏会说明。每行末尾的定位按钮点一下即定位该行。
- 复制文件：把文件或文件夹本身放到剪贴板，在文件管理器里粘贴得到该文件，在其他程序里粘贴得到它的路径。只有窗口版提供；浏览器页面的剪贴板只能放文字，Ctrl+C 仍复制路径。
- 右键或菜单键（Shift+F10）：定位、打开、复制文件、复制路径，分隔线后是跳到最新版（标「有更新版」的行）、排除此文件夹（文件夹行）或排除所在文件夹（文件行）、重新扫描。排除前会确认要排除的文件夹；它本身就是索引的文件夹时不显示这一项。
- 搜索框右侧的齿轮按钮或 Ctrl+, 打开「设置」，见下文「索引范围与设置」。
- 点列头按名称、路径、大小、修改时间排序，再点反向。默认最新在前。
- 拖动列头可以调整名称、路径、大小、修改时间四列的先后，定位按钮列固定在最后；也可在「设置」→「列顺序」里用「上移」「下移」调整，「恢复默认顺序」改回名称、路径、大小、修改时间。
- 鼠标停在结果行上，提示该行的完整路径。
- 类似版本：同一文件的多个版本（副本、带日期或版本号的另存、初稿与终稿等）归为一组，修改时间最新的一个在名称前标「最新」，其余标「有更新版」；结果照常显示、不折叠。悬停时另起一行写同组共几个、最新的是哪个；在「有更新版」的行上右键可「跳到最新版」。判定见下文「类似版本的判定」。
- 可以把结果拖到其他程序。
- F5 重新扫描；Ctrl+, 打开设置；Ctrl+L 回到搜索框；Esc 先清空搜索框（列表随之收起），再按一次关闭窗口。
- 搜索框为空时只显示搜索框一行，窗口在原位置变矮；输入第一个字就展开结果列表，高度恢复为上次展开时的高度；没有结果时也展开，并显示「没有找到」。删空搜索框或按 Esc 清空时收起。窗口最大化时不收起。收起时，搜索框内右侧用小字显示「共 N 项」或「索引中 42%」，复制、出错等提示也临时显示在这里；悬停搜索框可看到完整的索引状态和版本号。
- 窗口失去焦点（切到别的程序）时变为 70% 不透明，回到窗口时恢复；本窗口的右键菜单和对话框不算失去焦点。需要桌面开启窗口合成，没有合成时始终不透明。
- 关闭窗口时记住列宽、列顺序、窗口大小、是否最大化、窗口位置和排序方式，下次打开时恢复；存在 `~/.config/find-fast/ui-state.json`（权限 600），与设置分开，不影响索引。文件损坏或数值不合法时对应项用默认值（列顺序缺列、多列或有不认识的列时用默认顺序）；记住的位置已不在任何显示器上，或在 Wayland 下（程序不能指定窗口位置）时，位置交给桌面安排。浏览器页面不受这些影响。
- 列表展开时，状态栏左边是结果数与耗时，右边是条目总数、扫描进度、无法读取的文件夹数、更新方式（实时更新或定时更新）和版本号。

### 类似版本的判定

只看文件，不看文件夹，只在当前搜索结果里分组（不同文件夹的也算）。文件名去掉扩展名后，依次去掉下列标记，再忽略大小写、全角与半角、空格和括号的差别，剩下的部分相同、扩展名也相同的归为一组：

- 副本标记：`(1)`、`（2）`、`- 副本`、`_copy`、`copy of`；
- 开头的序号：`1 `、`02_`；
- 开头或结尾的日期：`20260101`、`2026-01-01`、`2026.1.1`、`260101`，可带括号；
- 版本号：`v2`、`V2.1`、`ver3`、`第二版`；
- 稿件词：初稿、二稿、三稿、终稿、定稿、修订版、修改版、最终版、最终稿、final、draft。

去掉标记后不到 2 个字的不分组。同组里修改时间最新的为「最新」，时间相同时取路径较短的。结果超过 100000 条时不分组，状态栏写明「结果过多，未标出类似版本」；5000 条以上的在后台计算，算完后标记出现。

### 浏览器页面

没有 python3-gi 时（或用 `--web`）启动本机网页服务并打开浏览器。功能：搜索、排序、结果表（每次 200 行，「显示更多」继续；悬停显示完整路径；拖动列头或在「设置」里调整列顺序，顺序记在本浏览器里）、打开、定位（每行末尾也有定位按钮）、复制路径、重新扫描、设置（齿轮按钮）、右键菜单（含排除）、退出。网页版的「添加文件夹……」用 zenity 弹出选择窗口，没有 zenity 时改为输入路径。

服务只监听 127.0.0.1 的随机端口，网址带本次启动生成的令牌；关闭页面后数秒内自动退出（刷新不算关闭），点「退出」立即结束；页面挂在后台不会被判为关闭；120 秒内没有页面打开也会退出。`--no-browser` 只输出网址。

### 命令行

```
python3 find_fast.py 查询词...            输出匹配的完整路径，最新在前
  --sort mtime|name|path|size  --asc / --desc   排序
  --regex          整个查询作为正则表达式
  --limit N        最多输出 N 条；--count 只输出条数；-0 用 NUL 分隔
  --update         先补扫有变化的文件夹；--rebuild 全部重扫
  --status         输出索引状态（JSON）
  --gtk / --web    指定窗口或网页；--no-browser 网页版只输出网址
  --toggle         窗口在前台时隐藏，否则显示（供全局快捷键使用）
  --remove-hotkey  删除本工具写入桌面设置的唤起快捷键
  --log-level DEBUG|INFO|WARNING|ERROR    日志级别（默认 WARNING，可用环境变量 LOG_LEVEL）
```

没有匹配时退出码为 1，查询写错时为 2。

## 索引范围与设置

默认索引家目录，以及 `/media`、`/mnt` 下挂载的本地磁盘。网络挂载（nfs、cifs/smb、sshfs 等，除 ntfs-3g、exfat 等本地格式外的 fuse 文件系统也按网络处理）和 `/proc`、`/sys` 等伪文件系统不索引；不跟随符号链接进入文件夹。

点搜索框右侧的齿轮按钮（窗口里也可按 Ctrl+,）打开「设置」：

- 索引的文件夹：可删除；「添加文件夹……」从系统选择窗口里选。
- 排除：可删除；「添加文件夹……」选一个文件夹按路径排除，或在输入框里写名称规则（如 `node_modules`、`*.tmp`）后点「添加」。
- 索引隐藏文件和文件夹：开关。
- 搜索词也匹配路径：默认打开，普通词在文件名和所在文件夹名里找；关掉后只在文件名里找。改这一项不重新扫描。
- 列顺序：「上移」「下移」与「恢复默认顺序」，点「保存」后生效。
- 「恢复默认」把面板里的值改回默认，点「保存」后才写入。

保存时先检查：索引的文件夹为空时不能保存；文件夹不存在、在网络挂载上、包含在另一个索引的文件夹里、排除路径不在任何索引的文件夹里时，先列出原因，确认后点「仍然保存」。同一个文件夹的不同写法自动合并，家目录下的文件夹写成 `~/` 形式。

保存后立即在后台更新索引，搜索不中断：只新增了排除时，直接从索引里去掉命中的条目，不重新扫描；改了索引的文件夹或删掉了排除规则时重新扫描（打开隐藏文件或删掉排除规则时要重新列出全部文件夹）。正在扫描时保存，会先停下当前扫描再按新设置开始。

设置存在 `~/.config/find-fast/config.json`，也可以手改，没有时用默认值：

```json
{
  "roots": ["~", "/media", "/mnt"],
  "exclude": ["node_modules", "__pycache__", "lost+found", "$RECYCLE.BIN", "System Volume Information"],
  "hidden": false,
  "match_path": true
}
```

- `roots`：要索引的文件夹（可写 `~`）；互相包含时只算外层。
- `exclude`：不带 `/` 的按名称排除（可用 `*` `?` 通配），带 `/` 或以 `~` 开头的按路径排除整个文件夹。
- `hidden`：是否索引以点开头的隐藏文件和文件夹。
- `match_path`：普通搜索词是否也匹配所在文件夹的名称，默认 `true`。
- `keys`、`toggle_default_done`：快捷键，以及默认唤起快捷键是否已处理过；由「设置」写入。

手改设置文件后，下次启动时全部重扫。

索引存在 `~/.cache/find-fast/index.bin`，权限 600。大小与修改时间在文件夹有变化时更新：窗口开着时由 inotify 实时更新；关着时的变化在下次打开时补扫。文件夹太多、超过系统 inotify 监听上限（`/proc/sys/fs/inotify/max_user_watches`）时，超出的部分每 5 分钟补扫一次，状态栏显示「部分文件夹定时更新」。

## 性能

在 GitHub Actions 的 Ubuntu 运行器上，用 `scripts/bench.py` 造的一百万条虚构条目测得：载入索引到可搜约 0.3 秒，内存峰值约 250 MB；普通词搜索与逐字输入每次 15 到 60 毫秒；搜索词同时出现在大量文件夹名里、结果成倍增多时（基准数据的文件夹名与文件名取自同一批词，是最不利的情况）每次约 60 到 120 毫秒；通配、扩展名、路径、正则等需要逐条多次判断的查询 60 到 130 毫秒，随机器快慢波动。

## 隐私

工具只读取文件夹列表，不读文件内容，不修改任何文件，运行时不访问网络。索引和设置只存在本机的 `~/.cache/find-fast`、`~/.config/find-fast`。
