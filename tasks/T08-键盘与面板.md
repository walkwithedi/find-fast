# T08 · 键盘、语法面板、右键菜单

**状态**：待做　**优先级**：P1　**平台**：双　**依赖**：T03　**预估**：1 人日

## 目标

手不离键盘能走完全程；常驻的百字语法说明改成按需面板，示例可点；右键菜单分组。

## 为什么

- 语法帮助常驻占两行高度，95% 时间没人看，需要时又读不进去。
- 键盘只能上下移动，40 条结果选第 30 条要按 30 次。
- 右键菜单平铺 7 项，全局动作与选区动作混排。

## 改动点

### Web

1. 删除 `<p class="help" id="help">`，新增 `<dialog id="keysDlg">`：两列（键位 / 语法），语法项可点。
2. 键位表用一份数据生成（便于与文档同步）：

```js
const KEYS = [
  ['搜索框', [['↓ ↑','选择'], ['Enter','打开'], ['Ctrl Enter','定位'],
             ['Ctrl C','复制文件'], ['Ctrl Shift C','复制路径'], ['Esc','清空 / 收起']]],
  ['全局',  [['F5','重新扫描'], ['Ctrl ,','设置'], ['?','本面板']]],
];
const SYNTAX = [
  ['报告 2026','多个词同时匹配'],
  ['报告|周报','任一'],
  ['!草稿','排除'],
  ['*.pdf','通配整个文件名'],
  ['ext:pdf;docx','按扩展名'],
  ['path:项目','只在完整路径里匹配'],
  ['regex:^IMG_\\d+','正则'],
];
```

3. `?` 打开面板（仅当输入框为空），`Ctrl+,` 打开设置，`Esc` 逐级退出。
4. 列表内 `Home/End/PgUp/PgDn`；可打印字符 → 焦点回输入框并追加。
5. 右键菜单重排为三组（打开类 / 复制类 / 全局类），快捷键右对齐。

### GTK

1. `?` 打开 `Gtk.Dialog`（或 `Gtk.Popover`）：`Gtk.Grid` 两列，语法示例用 `Gtk.LinkButton` 样式或可点的 `Gtk.Button`（`relief=none`）。
2. `on_entry_key` 增加 `Home/End/PgUp/PgDn`（已部分有），`on_tree_key` 增加 `?`、`Ctrl+,`。
3. 右键菜单加 `Gtk.SeparatorMenuItem` 分组，`Gtk.AccelLabel` 显示快捷键。
4. 现有 accel 机制（`load_keys` / `matches`）不动，新增动作只加在 `list_actions()` 之外的处理里。

## 验收

- [ ] 不碰鼠标：唤出 → `pdf` → ↓↓ → Enter → 打开成功
- [ ] `Ctrl+Enter` 定位、`Ctrl+Shift+C` 复制路径、`Ctrl+C` 复制文件（GTK）
- [ ] Web 端 `Ctrl+C` 在有文本选中时复制文本，不拦截
- [ ] `?` 面板打开时输入框为空；面板里点 `ext:pdf;docx` 自动填入并搜索
- [ ] 右键菜单三组，最后一项是「重新扫描」，快捷键右对齐
- [ ] `Home/End` 在输入框有选区时不抢键（选区存在则走文本行为）
- [ ] 列表内按字母 → 焦点回输入框且字母被追加
- [ ] `Esc` 三级退出正确，不直接退程序
- [ ] 焦点环在所有按钮/chip 上可见

## 风险

- `?` 在中文输入法下是 `、`/`？`，必须判断 `event.key === '?'` 且 `!isComposing`。
- 不要用 `keypress`（已废弃且在部分输入法下不触发）。
- GTK 的 `Gtk.Dialog` 默认有「关闭」按钮区，注意 `Esc` 关闭后焦点回 `entry`。
- Web 的 `<dialog>` 在 Safari 旧版无 `showModal`，本项目只面向 Chromium/Firefox，可接受。
