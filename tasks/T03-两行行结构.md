# T03 · 两行行结构与列表重绘

**状态**：进行中　**优先级**：P0　**平台**：双　**依赖**：T02　**预估**：2 人日

## 目标

结果行从「五列表格」变成「两行一条」：文件名一行、路径一行、元信息右对齐。最宽的空间给文件名，路径只留末两级。窗口 700px 宽时不再横向滚动。

## 为什么

- 路径列被设为 `expand`，吃掉全部剩余宽度（`find_fast_gtk.py:804`、`find_fast.html:31` 的 `min-width:560px`）。
- 实测连续 8 行路径相同，纯浪费；760px 下文件名被挤成两截。

## 改动点

### Web（`find_fast.html`）

1. 删除 `<table>` 全套（`thead`、`#hName/#hPath/#hSize/#hTime`、`#hLoc`、`tbody#rows`），换成：

```html
<div class="listwrap">
  <div id="rows" role="listbox" aria-label="搜索结果" tabindex="0"></div>
  <div id="listEnd" class="end-note" hidden role="presentation"></div>
  <div id="empty" class="empty" hidden></div>
</div>
```

2. 重写 `renderRow(r)`：

```html
<div class="row" role="option" id="opt-K" data-k="K" aria-selected="false">
  <span class="ico" aria-hidden="true"><svg width="17" height="17"><use href="#i-image"/></svg></span>
  <span class="body">
    <span class="line1">
      <span class="nm">NAME_HTML</span>
      <span class="tag new">最新</span>
    </span>
    <span class="pth">DIR_HTML</span>
  </span>
  <span class="meta"><span class="sz">2.28 MB</span><span class="tm">3 小时前</span></span>
</div>
```

3. 删除 `.kind`（emoji）、`td.*`、`th.*`、`tr[aria-selected]` 样式；保留 `design/web-components.css` 里的 `.row/.nm/.pth/.meta/.tag`。
4. `select(k, focus)`：用 `$('rows').children[k]`，更新 `aria-activedescendant`；`scrollIntoView({block:'nearest'})`。
5. `loadMore()`：追加行；结束时显示 `#listEnd`（`已显示全部 N 个结果`），它必须在 `#rows` **外面**。
6. 删除 `#more` 按钮，滚动到底自动加载。

### GTK（`find_fast_gtk.py`）

1. Store 追加两列：`Gtk.ListStore(str, str, str, str, str, str, str, str, str)`（7=主 markup，8=元信息 markup）。
2. 删除 `for i, (key, label) in enumerate(COLUMNS)` 建列整段，改为两列（详见 `docs/09` 4.1 的代码片段）。
3. `tv.set_headers_visible(False)`；`set_fixed_height_mode(True)`；`measure_row_height()` 返回 `48, True`；`update_rows()` 里去掉表头高度。
4. 删除 `COLUMNS`、`LOCATE_ICONS`、`DATA_COLUMNS`、`column_width/order/set_column_order/column_drop_ok`、`dim_tags()` 及其 `style-updated` 连接；`load_ui_state` 对 `order/width` 的读取保留但不使用。
5. `fill()` 组装 markup：名称行（可带版本标签）+ `\n` + 路径行（`short_dir`）。
6. `on_header`、`update_sort_indicators` 删除（排序走 T06 的菜单）。

## 实现要点

- 行高 48 固定：名称 14/500 行高约 19、路径 12.5 约 17、间距 2、上下留白 10。
- 图标 17 居中，列宽 20；元信息列 116，等宽数字。
- 路径用 `core.short_dir()` 的输出，**不要**在前端二次截断（否则高亮区间对不上）。
- 标签「最新」用 `--accent-soft` 底，`--ink-3` 文字；「有更新版」用默认边框样式。
- 文件夹图标 `--ico-folder`，其余 `--ink-3`；选中行图标转 `--accent`。
- 悬停 `--hover`，选中 `--sel` + 左 3px 条（上下缩进 8）。
- Web 端每行**不绑定事件**，用 `#rows` 上的委托（`mousedown`/`dblclick`/`contextmenu`）。

## 验收

- [ ] 行高 48±1，连续 10 行上下对齐无跳动
- [ ] 800px / 700px 宽无横向滚动
- [ ] 长文件名（>60 字符）省略号结尾，时间列不被挤压
- [ ] 路径只显示 `~/…` 或 `…/` 末两级，tooltip 有完整路径
- [ ] 列表末尾提示出现，且 ↓ 能到末条、↑ 能回第一条
- [ ] 分页加载 400 行后，第 300 行可点选、可键盘选中（下标不错位）
- [ ] GTK 行内两行文本不重叠、不裁切（截图）
- [ ] 删除的旧 CSS/函数零残留（`grep -n "th\[aria-sort\]\|td.loc\|#more" find_fast.html`）
- [ ] 类似版本标签仍显示在名称行末尾

## 风险

- **下标映射**：任何插在 `#rows` 里的非行元素都会毁掉 `children[k]`。末尾提示、骨架、空状态都必须放在 `#rows` 之外。
- GTK 的 `CellRendererText` 对 `markup` 里的 `\n` 支持正常，但 `ellipsize` 作用于整段：名称过长时只截名称行，路径行靠 `short_dir` 保证短。
- 删列头后 `update_rows()` 若仍读 `self.columns['name'].get_button()` 会抛 `AttributeError`（NoneType），注意一并改。
- 不要给 `.row` 加 `border-radius` 或间距——行必须连续，否则 48px 网格出现缝。
