# T04 · 预览面板与操作收编

**状态**：完成　**优先级**：P0　**平台**：双　**依赖**：T03　**预估**：2 人日

## 目标

选中一行，右侧显示它的完整信息与三个操作：打开、定位、复制路径。删除列表上方的操作按钮条与每行末尾的定位按钮。

## 为什么

按钮在列表上方，视线要上下往返；`重新扫描` 是全局动作却混在选区动作里；行尾定位按钮让每行多一列、窄窗口被迫横向滚动，而 GTK 侧根本没有这个按钮——两平台行为不一致。

## 改动点

### Web

1. 新增 `<aside id="preview" class="preview" aria-label="详情">`（`.stage` 右侧，宽 340）。
2. 删除 `.actions` 整块（`#open` `#folder` `#copy` `#rescan` 按钮），但**保留四个 id 的元素**：
   - `#open`、`#folder`、`#copy` 移入预览面板的按钮区（事件绑定不动）；
   - `#rescan` 移入「更多」菜单（`#moreMenu`）。
3. 新增 `renderPreview(e)`：未选中时渲染索引信息卡；选中时渲染图标块、名称、类型、路径框、四行元信息、操作按钮、键位提示。
4. `select()` 末尾调用 `renderPreview()`；`search()` 结果为空时也调用（回到信息卡）。
5. 操作按钮的 `disabled` 由 `renderPreview()` 统一控制，删除 `select()` 里的 `['open','folder','copy'].forEach(...)`。

### GTK

1. `list_area` 里 tree 之后加 `self.preview`（`Gtk.Box`，`set_size_request(340, -1)`，class `preview`）。
2. 结构：`Gtk.Box(横向)`（图标 + 名称/类型）→ 路径 `Gtk.Entry(editable=False)` + 复制按钮 → `Gtk.Grid` 元信息 → 主按钮「打开」→ `Gtk.Box(横向)` 两个次按钮 → 键位提示 `Gtk.Grid`。
3. `on_selection_changed` 里更新面板；无选中时显示索引信息（条目数/文件夹数/监听状态）。
4. 宽度 <960 时 `self.preview.hide()`（在 `on_configure` 里判断一次，不要每帧）。
5. 右键菜单保留全部操作（面板隐藏时的唯一入口），并按 `can_exclude` 置灰。

## 内容规格

| 字段 | 来源 |
|---|---|
| 图标 | `category()` → `i-*` / 主题图标名 |
| 名称 | `r.name`（折行，最多 3 行） |
| 类型行 | `PDF 文件` / `文件夹`（`EXT` 大写 + `文件`） |
| 路径 | `r.path` 完整路径，可选中复制 |
| 大小 / 修改时间 / 类型 / 命中 | 大小用 `size_text`；时间用 `human_time`（`YYYY-MM-DD HH:MM`，不是相对时间）；类型同上；命中 = 名称 / 路径 / 名称与路径（来自高亮结果） |
| 操作 | 打开（主）、定位、复制路径；GTK 额外「复制文件」 |
| 键位提示 | 见 `docs/04` 6.2 |

## 验收

- [x] 选中行 → 面板立即更新；切换 10 行无残影、无布局抖动
- [x] 未选中时显示索引信息卡（条目数、文件夹数、监听状态），不显示「请选择」
- [x] 顶部操作条消失，行尾定位按钮消失（Web `td.loc` 与 GTK `locate` 列都没了）
- [x] 面板宽度 340 固定，长名称折行不撑破；路径框 `word-break` 生效
- [x] 1080px 以下面板隐藏，右键菜单能完成打开/定位/复制
- [x] GTK 面板隐藏阈值 960，且隐藏后列表宽度自动补满
- [x] 复制路径后有 toast，内容为完整路径
- [x] 「重新扫描」只在更多菜单与 F5 里出现

## 风险

- Web 删除 `.actions` 时不要删掉 `#open` 等元素的 id，`openCurrent()` 里 `$('open').disabled` 之类会报 null；建议保留 id、只挪位置，并把这些引用改成「可空」判断。
- GTK 的 `Gtk.Entry` 设为 `editable=False` 后仍可选中复制，但需要 `set_can_focus(True)` 才能用键盘选。
- 面板里的「命中」字段依赖 T02 的 `name_html`/`dir_html`，若两者都为空则显示「—」，不要显示「名称」。
