# T01 · 设计令牌与主题

**状态**：进行中　**优先级**：P0　**平台**：双　**依赖**：T00　**预估**：0.5 人日

## 目标

把散落的颜色、字号、间距收成一套令牌，Web 与 GTK 共用同一份取值；深浅主题都能一键切换。

## 改动点

| 文件 | 改什么 |
|---|---|
| `find_fast.html` | `<style>` 顶部替换旧的 `:root{--bg:#f6f7f9…}` 与 `@media (prefers-color-scheme: dark)` 两块，换成 `design/tokens.css` 全文 |
| `find_fast.html` | `<html data-theme>` 承载主题；首屏按 `prefers-color-scheme` 初始化，用户手动切换后写 `localStorage['find-fast.theme']` |
| `find_fast_gtk.py` | 新增 `load_css(theme)`：读 `design/gtk.css` 的色块，按主题替换后 `CssProvider.load_from_data`；在 `Window.build()` 末尾调用 |
| `find_fast_gtk.py` | 主题切换：`Gtk.Settings.get_default().set_property('gtk-application-prefer-dark-theme', dark)` + 重新注入 CSS |
| 新增 | `find_fast_theme.py`（可选）：把 `tokens.json` 读成 dict，供 Python 生成 GTK CSS 与 Pango 高亮色 |

## 实现要点

1. **令牌是唯一来源**。组件样式里出现 `#` 开头的颜色即视为不合格（唯一的例外是 Pango markup 里的字符串，从令牌取）。
2. Web 端旧变量名（`--card` `--text` `--muted` `--sel`）全部替换：`--card → --surface`、`--text → --ink`、`--muted → --ink-3`、`--sel → --sel`（语义变了，注意 `#ctx button:hover{background:var(--sel)}` 要改成 `--surface-3`）。
3. GTK 端不要试图用 CSS 变量（GTK3 没有），用 `@define-color` + Python 端字符串替换；模板文件即 `design/gtk.css`。
4. 深色下 Pango 高亮色必须换一套：`#3a3320` 底 + `#ffd98a` 前景（`rgba` 不被 Pango 支持）。
5. 焦点环统一写在 tokens.css 的一条 `:where(...):focus-visible` 里，删除各组件自己的 outline 声明。

## 风险

- GTK 主题（Adwaita / Arc / 其他）会覆盖部分控件样式，`CssProvider` 优先级已设为 `APPLICATION`，仍可能被主题的 `!important` 顶掉；遇到就针对具体控件加 class，不要全局 `*` 强改。
- 不要改 `find_fast.html` 里升级面板（`#upgrade`）的样式类名，那段 JS 有 `classList` 依赖。
