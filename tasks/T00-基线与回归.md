# T00 · 基线与回归保护

**状态**：完成　**优先级**：P0　**平台**：双　**依赖**：—　**预估**：0.5 人日

## 目标

在动任何代码之前，把 v0.6.0 的可运行状态、可回归行为、可对比截图固定下来。后面每个任务都要拿它对照。

## 步骤

1. 把 `source/find-fast-v0.6.0/` 复制成工作仓库根目录（`find_fast.py` 在根上），`git init`，提交 `chore: 导入 v0.6.0 基线`，打 tag `v0.6.0-base`。
2. 起网页版，记录 URL 与 token：
   ```bash
   python3 find_fast.py --web --no-browser
   ```
3. 起 GTK 版（无显示器用 `xvfb-run -a`），确认能搜出结果。
4. 逐条验证 `TASKS.md` 的「回归保护清单」9 项，能过就在本文件末尾打勾；不能过的记下原因（可能是环境问题，不是代码问题）。
5. 截 4 张基线图存 `docs/baseline/`：结果列表、无结果、窄窗口（760px）、设置对话框。与 `resources/screens/before-*.png` 对比，确认是同一版。
6. 跑一次 `python3 -m pytest tests/ -q`，确认**当前是失败的**（高亮与时间函数还没实现）——这是 T02 的起点。
